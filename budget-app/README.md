# הכיס המשפחתי – ניהול תקציב משפחתי

אפליקציית ווב (עובדת גם בטלפון וניתנת להתקנה כאפליקציה) לניהול תקציב משפחתי:

- **ייבוא קובץ התקציב הקיים** (אקסל עם גיליון לכל שנה ועמודה לכל חודש): קטגוריות, ביצוע חודשי, תקציב, ומצב נכסים וחובות.
- **ייבוא מהבנק ומחברות האשראי**: Excel / CSV / PDF. זיהוי עמודות אוטומטי, הפרדת הכנסות מהוצאות, וסימון חיוב האשראי בבנק כ"העברה" כדי שלא ייספר פעמיים.
- **רישומים מוואטסאפ**: הדבקת הודעות כמו "סופר 350" או העלאת צ'אט מיוצא.
- **סיווג אוטומטי** לפי בתי עסק מוכרים, ולמידה מכל שיוך ידני.
- **דשבורד חודשי**: הכנסות מול הוצאות, חריגות מהתקציב ותובנות.
- **בניית תקציב** לפי ממוצע של 12 חודשים, וזיהוי הוצאות לא סדירות (חשמל דו-חודשי, חגים).
- **הון משפחתי**: נכסים, חובות ושווי נקי.
- **קורס ניהול כלכלי**: 16 שיעורים עם טיפים, שאלות וצעדים מעשיים.

## פרטיות
כל הנתונים נשמרים רק בדפדפן (localStorage). קבצים נקראים מקומית ולא נשלחים לשום שרת.
מומלץ להוריד גיבוי מדי פעם מ"הגדרות וגיבוי".

## הרצה
```bash
cd budget-app
npm install
npm run dev
```
בנייה לפרסום: `npm run build`. התיקייה `dist/` היא אתר סטטי שאפשר להעלות ל-Cloudflare Pages, Netlify או GitHub Pages.
