API וחיבור בין מערכות — מאפס

להבין מה קורה כשמערכת אחת ״מדברת״ עם אחרת — ולחבר בלי מתכנת ובלי להיבהל.

א
הסיפור של אהרןמנהל מכללה ללימודי תעודה

האקסל של יום ראשון

כל בוקר, יועצת הלימודים של אהרן הורידה קובץ אקסל מפייסבוק, העתיקה את הלידים לקובץ אחר, ורק אז התחילה להתקשר.

ביום עמוס, ליד מחכה 14 שעות עד שמישהו בכלל רואה אותו.

אהרן שאל את איש המחשבים: ״אפשר לחבר את זה אוטומטית?״

התשובה: ״בטח, עם API וובהוק.״

אהרן הנהן — ולא הבין מילה.

בשיעור הזה תלמדו

  • API, Webhook ו-JSON — במילים של בני אדם
  • איך לצייר מפה של הדרך שליד עובר
  • לחבר בלי לכתוב קוד
אם תזכרו רק דבר אחד

API הוא מלצר: אתם מבקשים, הוא מביא מהמטבח. Webhook הוא פעמון: המטבח מצלצל לכם כשהמנה מוכנה.

שלוש מילים מפחידות, שלושה רעיונות פשוטים

רגע, מה זה API?

דלת מסודרת שדרכה מערכת אחת מבקשת או שולחת מידע למערכת אחרת. ״תביא לי את כל הלידים מהיום.״

רגע, מה זה Webhook?

הודעה אוטומטית שנשלחת ברגע שמשהו קורה. ״נכנס ליד חדש!״

רגע, מה זה JSON?

השפה שבה המידע נשלח. פשוט רשימה של ״שדה: ערך״.

{ "name": "דנה", "phone": "0501234567", "course": "הנהלת חשבונות" }
תחשבו על זה ככה

במסעדה: אתם (מערכת אחת) מזמינים מהמלצר (API). כשהמנה מוכנה, הטבח מצלצל בפעמון (Webhook). והתפריט כתוב בשפה שכולם מבינים (JSON).

זהו. כל השאר זה פרטים.

קודם מציירים, אחר כך מחברים

לפני שמחברים — מציירים את המסלול של ליד:

  • מאיפה הוא מגיע? טופס באתר, טופס בפייסבוק, וואטסאפ, טלפון.
  • לאן הוא צריך להגיע? CRM, גיליון, הודעה ליועצת.
  • אילו פרטים עוברים? שם, טלפון, קורס, המדבקה (UTM), תאריך.
  • מה קורה אם החיבור נשבר? מי מקבל התראה?

לחבר בלי מתכנת

יש כלים שבנויים בדיוק לזה: Make, Zapier, n8n. כולם עובדים באותה צורה:

  • מתי? (״נכנס ליד חדש בפייסבוק״)
  • מה לעשות? (״הוסף ל-CRM, שלח וואטסאפ ליועצת״)
תחשבו על זה ככה

זה כמו מתכון: ״כש-X קורה, תעשה Y ואז Z.״

רוב מערכות ה-CRM כבר מציעות חיבור מוכן לפייסבוק. מתחילים ממה שכבר קיים.

טיפהסכנה: חיבורים נשברים בשקט. קובעים התראה כשמשהו נכשל, ובודקים פעם בשבוע.
מה אהרן עשה

דקה במקום 14 שעות

אהרן ואיש המחשבים חיברו בעזרת Make:

ליד חדש בפייסבוק ← נכנס ל-CRM עם כל הפרטים ← הודעת וואטסאפ ליועצת: ״ליד חדש: דנה, הנהלת חשבונות, 050...״

עכשיו ליד מגיע ליועצת תוך פחות מדקה.

אחרי חודש: היועצת מצליחה לדבר עם 80% מהלידים, במקום 45%. אותם לידים, אותו תקציב. רק מהר יותר.
