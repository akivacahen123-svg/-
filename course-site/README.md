# לא לצאת פראייר בפרסום — אתר הקורס

אתר סטטי (HTML + CSS) בעיצוב של דף הנחיתה. פרויקט נפרד — לא קשור לשאר הקבצים בריפו.

## מבנה
- `index.html` — עמוד הבית / מכירה
- `curriculum.html` — תוכנית הלימודים (22 שיעורים ב-6 שלבים)
- `lessons/lesson-01.html` … `lesson-22.html` — עמוד לכל שיעור
- `assets/css/style.css` — מערכת העיצוב (צבעים, פונט, כרטיסים)
- `assets/img/` — תמונת הרקע מדף הנחיתה

## עריכה
כל הטקסטים, השיעורים והמחיר נמצאים בקובץ אחד: `build.py`.
משנים שם ומריצים:

```
python3 build.py
```

## מה עוד חסר
- תוכן השיעורים עצמם (סרטון / טקסט) — יש מקום מסומן בכל עמוד שיעור.
- קישור לדף התשלום — משנים את `PURCHASE_URL` ב-`build.py`.
- קבצי העבודה (workbook).
