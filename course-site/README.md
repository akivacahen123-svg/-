# לא לצאת פראייר בפרסום — אתר הקורס

אתר סטטי (HTML + CSS + JS) בעיצוב של דף הנחיתה. פרויקט נפרד — לא קשור לשאר הקבצים בריפו.

## מה יש באתר
| עמוד | מה זה |
|---|---|
| `index.html` | עמוד הבית / מכירה |
| `checklist.html` | **הצ׳ק ליסט החינמי** — 20 פעולות לפני קמפיין, אינטראקטיבי, להדפסה |
| `purchase.html` | עמוד רכישה (₪500) |
| `curriculum.html` | תוכנית הלימודים + מעקב התקדמות |
| `lessons/lesson-01…22.html` | 22 שיעורים מלאים |
| `toolkit.html` + `tools/*.html` | ערכת 9 כלי עבודה |
| `glossary.html` | מילון מונחים עם חיפוש |
| `welcome.html` | כניסה לקורס עם קוד גישה (לכאן מפנים אחרי תשלום) |
| `accessibility.html`, `terms.html`, `privacy.html` | הצהרת נגישות, תנאי שימוש, מדיניות פרטיות |
| `landing/index.html` | **דף הנחיתה המעודכן** — קובץ יחיד (עם התמונה בתוכו) להעלאה ל-Lando |
| `sitemap.xml`, `robots.txt` | קבצי SEO |

### מה מחובר
- **גישה לקורס** — שיעור 01, הצ׳ק ליסט, המילון והעמודים הכלליים פתוחים. שיעורים 02–22 וכל הכלים ננעלים
  עד שמזינים קוד גישה (`ACCESS_CODE` ב-`build.py`). אחרי תשלום מפנים את הקונה ל-`welcome.html?code=<הקוד>`
  והקורס נפתח אוטומטית, או שולחים לו את הקוד במייל.
- **תוסף נגישות** בכל עמוד: הגדלת טקסט (3 רמות), ריווח, ניגודיות גבוהה, גווני אפור, הדגשת קישורים,
  גופן קריא, עצירת אנימציות, סמן גדול. וגם: ״דילוג לתוכן״, ניווט מקלדת, תוויות לשדות.
- **SEO** — כותרת ותיאור לכל עמוד, canonical, Open Graph, נתונים מובנים (Course, FAQPage, LearningResource
  עם סימון paywall, BreadcrumbList, DefinedTermSet), sitemap.xml, robots.txt, favicon. הכלים וכניסה לקורס ב-noindex.
- **עוגיות ומדידה** — ממלאים `GA4_ID` / `META_PIXEL_ID` ב-`build.py`; באנר ההסכמה מופיע אוטומטית,
  והקוד נטען רק אחרי אישור.

### מבנה כל שיעור (microlearning)
מטרה אחת · בסוף השיעור תדעו · השורה התחתונה · 2–4 חלקים קצרים · דוגמה מהשטח עם מספרים ·
פראייר מול מקצוען · משימה למחר בבוקר · קישור לכלי · בוחן של 3 שאלות · כפתור ״סיימתי״.

### ערכת הכלים (עובדת בדפדפן, שומרת אוטומטית, מדפיסה ל-PDF)
מחולל בריף · מחשבון תקציב ויעדים · מחולל UTM (עם היסטוריה וייצוא CSV) · טבלת בקרה שבועית ·
אבחון קמפיין · דשבורד · מחולל דוח חודשי · צ׳ק־ליסט QA (45 בדיקות) · פרויקט גמר.

## עריכה
- טקסטים כלליים, מחיר, מבנה הקורס ועמוד הבית: `build.py`
- תוכן השיעורים: `content/part1.py` (01–08), `content/part2.py` (09–15), `content/part3.py` (16–22)
- צ׳ק ליסטים ומילון: `content/extras.py`

אחרי כל שינוי מריצים:

```
python3 build.py
```

## לפני העלייה לאוויר
- **קישור תשלום** — למלא את `PAYMENT_URL` ב-`build.py`, ובמערכת הסליקה להגדיר דף הצלחה:
  `<כתובת האתר>/welcome.html?code=<ACCESS_CODE>`.
- **פרטי קשר** — למלא `CONTACT_EMAIL` ו-`CONTACT_PHONE` (מופיעים בהצהרת הנגישות ובדפים המשפטיים).
- **בדיקה משפטית** — הצהרת הנגישות, תנאי השימוש ומדיניות הפרטיות נכתבו כטיוטה מקצועית; מומלץ שעורך דין יעבור עליהם.
- **כתובת האתר** — `SITE_URL` משמש ל-canonical ול-sitemap. לעדכן אם האתר עולה לכתובת אחרת.
- **טפסים** — הטפסים שולחים POST רגיל (כמו בדף הנחיתה). לבדוק שהחיבור ל-Lando / CRM עובד.
- **רמת ההגנה** — הנעילה פועלת בדפדפן. היא עוצרת גולש רגיל, אבל מי שיודע לקרוא קוד מקור יכול לעקוף אותה.
  להגנה מלאה מעלים את `lessons/` ו-`tools/` מאחורי סיסמה בשרת או לפלטפורמת קורסים.
- ההתקדמות, הסימונים ומה שמוזן בכלים נשמרים בדפדפן של כל משתמש (localStorage).
